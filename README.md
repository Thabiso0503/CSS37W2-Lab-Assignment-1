# 🌐 Software Engineering II — Web Application Development

## CSS37W2 | Lab Assignment 1

This repository contains my implementation and documentation for
**Lab Assignment 1** for Software Engineering II.

The purpose of this laboratory is to develop a practical understanding
of **HTTP, web servers, application servers, static and dynamic web
applications, and web hosting**.

The lab specifically focuses on working with:

- Apache Web Server
- XAMPP
- Apache Tomcat
- HTML
- PHP
- JSP
- HTTP
- Static websites
- Dynamic websites
- Web hosting

---

# 🎯 Lab Objectives

The main objectives of this laboratory are to:

- Understand how web servers work
- Understand how application servers work
- Develop practical skills in setting up a web server
- Deploy a website locally
- Access a website through different servers
- Investigate web servers vs application servers
- Investigate static vs dynamic websites
- Deploy a website using a free web hosting service

These objectives are based on the requirements specified in the
lab assignment.
