# 🎯 Lab Objectives

The main objectives of this laboratory are to:

- Understand how HTTP works
- Understand how web servers work
- Understand how application servers work
- Develop practical skills in setting up a web server
- Install and configure XAMPP
- Configure and use the Apache web server
- Create and serve static web pages
- Create and test dynamic web pages
- Understand the difference between static and dynamic websites
- Understand the difference between web servers and application servers
- Configure and use Apache Tomcat
- Experiment with JSP
- Deploy a website locally
- Test websites using a web browser
- Set up a web account using a free web hosting service
- Deploy a website to the internet
- Document the development and deployment process
