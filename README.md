# Software Engineering II – Web Application Development Lab

## CSS37W2 Lab Assignment 1

This repository contains my implementation of Lab Assignment 1 for
Software Engineering II.

The purpose of this lab is to develop a practical understanding of
web servers, application servers, HTTP, static and dynamic web
applications, and basic web application development.

## Lab Objectives

The lab focuses on:

- Understanding web servers and application servers
- Setting up a local web server using XAMPP
- Working with Apache Tomcat
- Creating basic HTML web pages
- Understanding static and dynamic web applications
- Deploying a website locally and online
- Comparing web servers and application servers
